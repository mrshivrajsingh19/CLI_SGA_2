DESIGNED REAL-TIME MONITORING PIPELINE:

tail -f system.log | grep "ERROR" > error_report.txt 2> /dev/null

Explanation:
The tail -f command continuously monitors the log file for newly added entries. The pipe (|) sends the output of tail to grep, which filters only ERROR messages. The > operator redirects the filtered messages to error_report.txt, while 2> /dev/null suppresses unnecessary error messages. This pipeline provides an efficient way to continuously monitor a log and maintain a separate ERROR report.
