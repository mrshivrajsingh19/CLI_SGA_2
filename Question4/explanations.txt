QUESTION 4 - EXPLANATIONS

1. tail -f system.log
tail -f continuously monitors the log file and displays newly appended entries in real time.

2. grep "ERROR"
grep filters the incoming log entries and selects only lines containing ERROR messages.

3. Pipe (|)
The pipe sends the output of tail directly to grep, allowing commands to work together without creating unnecessary intermediate files.

4. Redirection (>)
The > operator redirects the filtered ERROR messages into error_report.txt, creating a separate report file.

5. /dev/null
/dev/null discards unwanted output. Redirecting unnecessary error output to /dev/null keeps the terminal clean.

6. Complete pipeline
tail -f system.log | grep "ERROR" > error_report.txt 2> /dev/null

This pipeline continuously monitors the log, extracts ERROR messages, stores them in a separate report, and suppresses unnecessary error output.
