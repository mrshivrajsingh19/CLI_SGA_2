QUESTION 5

Recovery mechanisms available in vi:

1. Swap Files (.swp)
vi automatically creates a swap file while editing. If the system crashes, the swap file can be used to recover unsaved changes.

2. Undo History
Undo allows recently made changes to be reversed during the editing session. However, it cannot reliably recover work after the editor has closed unexpectedly.

3. Registers
Registers temporarily store copied or deleted text. They help restore accidentally deleted content but are not primarily intended for crash recovery.

4. Backup Files
Backup files preserve a previous version of the original file before editing. They protect the earlier version but may not contain the latest unsaved changes.

5. Auto-Recovery
vi can detect a swap file after an unexpected crash and provide an option to recover the unsaved editing session.

Most Reliable Recovery Strategy:

The most reliable recovery strategy is to use the swap file together with vi's recovery feature. The swap file preserves the editing session, allowing unsaved changes to be recovered after a crash. Backup files provide an additional safeguard by preserving the previous version of the configuration file.
