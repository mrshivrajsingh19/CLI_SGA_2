QUESTION 3 - EXPLANATIONS

1. open()
open() creates or opens the employee data file and returns a file descriptor for low-level file operations.

2. write()
write() stores employee records directly in the file using the file descriptor.

3. lseek()
lseek() moves the file offset to a specific position, allowing a particular record to be accessed without processing the entire file.

4. read()
read() retrieves employee records from the current file position. Combined with lseek(), it allows efficient random access.

5. Updating records
For fixed-size records, lseek() moves directly to the selected record and write() replaces it without rewriting the entire file.

6. close()
close() releases the file descriptor after file processing is complete.

7. Overall solution
open(), read(), write(), lseek(), and close() provide low-level Linux system-call-based file processing and efficient record access.
